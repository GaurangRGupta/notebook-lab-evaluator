## Why these files are a pilot note

One person wrote almost all of them. The only same-lab pair is the two Lab 11 PCA notebooks. A split of one author's files does not show how the grader treats a class. The notebooks also have no written answers, so the explanation mark on a pilot would be low. That low mark would describe the file. A later write-up should say so.

A later pilot, if the group writes one, can use Lab 2 (linear regression) and Lab 11 (PCA on churn). The lecture notebook on the same topic is the source of the lab card: the question, the reference explanation, and the expected output. Two people in the group mark code, explanation, and documentation, using `docs/annotation_guidelines.md`. That guide is still a draft, so the group agrees it before marking. This pilot has not been built.

## Where the real set still has to come from

The handout's source is the class's own lab submissions. `data/class/` is the empty place for those files. `docs/datasheet.md` section B stays blank until the files, the question sheets, and the human marks exist. The 10 synthetic notebooks stay the development set.

This package does not contact the faculty or anyone else. Collecting the class files is a step for the group, after permission.
