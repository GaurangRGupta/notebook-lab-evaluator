# Reference files

One folder per lab, named with that lab's `assignment_id` from `manifest.csv`.

Each folder needs:

- `template.ipynb`: the notebook the class was given
- `reference_solution.ipynb`: a solution written from the official question sheet
- `reference_explanations.json`: the explanation text and concepts for each task
- `expected_outputs.json`: what a correct saved output contains
- `rubric.json`: code 8, explanation 8, documentation 4

Write these from the official question sheet. A student notebook is not the reference, including the best one in the pile.
